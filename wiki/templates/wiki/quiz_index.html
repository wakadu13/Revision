Aucun set de QCM pour l'instant

Ajoutez un fichier .json dans le coffre pour créer un set. Le nom du dossier qui le contient devient sa catégorie. Exemple minimal :

{
  "titre": "Mon premier set",
  "questions": [
    {"type": "QCM", "question": "2 + 2 = ?", "choix": ["3", "4", "5"], "reponses": [1]}
  ]
}

Types disponibles : QCM, QCR (plusieurs bonnes réponses), TROU (texte à trous), QRC (réponse courte : traduction, synonyme) et FLASHCARD (recto/verso).
