    Plan

    Les titres de la page apparaîtront ici.

    Raccourcis

    • Tapez [[ pour lier une page, ![[ pour intégrer une image ou une note.
    • Ctrl+clic sur un lien l'ouvre dans un nouvel onglet.
    • Ctrl+S enregistre, Ctrl+E bascule en lecture ; « Côte à côte » montre le rendu pendant la saisie.
    • Tapez # pour un tag, [! dans un encadré pour son type. Un brouillon non enregistré est retrouvé à la prochaine ouverture.
    • Ctrl+B / I gras, italique · Ctrl+K lien · Ctrl+Entrée coche une tâche.
    • Ctrl+F rechercher et remplacer · Tab indente une liste.
    • Ctrl+Maj+F plein écran : la barre d'outils revient en touchant le haut de l'écran avec la souris, le menu à gauche, ce panneau à droite. Échap pour quitter.
    • Formules LaTeX : $…$ dans le texte, $$…$$ en bloc (bouton ∑ ou Ctrl+Maj+M). Elles s'affichent rendues ; cliquez dessus pour modifier le LaTeX.
    • Un cours en LaTeX ? Collez-le ou ouvrez le .tex (menu Fichier) : il est converti en page.
    • Collez ou glissez une image ou un PDF dans le texte : il est ajouté au coffre (![[cours.pdf]] affiche le lecteur PDF dans la page). Glissez un .md pour insérer son contenu.
