Bienvenue sur le wiki du **ProjetPluri** !

Chaque fichier `.md` du dossier `vault/` devient automatiquement une page. Ce dossier est un coffre [Obsidian](https://obsidian.md) : on peut l'ouvrir directement dans Obsidian pour écrire les notes, puis les consulter ici.

## Pour commencer

- [[Syntaxe Obsidian]] : tout ce que le wiki sait afficher
- [[Projet Pluri|Le projet]] : la page principale du projet
- [[Idées]] : une note en vrac

> [!tip] Créer une page
> Écrivez un lien vers une page qui n'existe pas encore, comme [[Planning]]. Il apparaît en pointillés ; créez ensuite `Planning.md` dans le coffre et le lien devient actif.
