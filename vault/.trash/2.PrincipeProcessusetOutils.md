# InfoSec — Principes, Processus & Outils

> [!info] Résumé en 2 phrases
> L'InfoSec repose sur des principes fondamentaux (CIA Triad + extensions) qui guident la protection des données et systèmes. Ces principes se traduisent en processus concrets et en un arsenal d'outils spécialisés.

---

## Les 6 Principes Fondamentaux

> [!abstract] CIA Triad — Le cœur de l'InfoSec
> **Confidentiality · Integrity · Availability**
> Ces trois principes forment la base de toute politique de sécurité.

| Principe | Objectif | Implémentation |
|---|---|---|
| **Confidentiality** | Accès réservé aux entités autorisées | Chiffrement, access controls |
| **Integrity** | Exactitude et complétude des données | Hashing, signatures numériques |
| **Availability** | Accessibilité quand nécessaire | Redondance, disaster recovery |
| **Non-repudiation** | Impossible de nier une action | Signatures numériques, audit logs |
| **Authentication** | Vérification d'identité | Passwords, biométrie, MFA |
| **Privacy** | Protection des données personnelles | Data minimization, gestion du consentement |

---

## Processus Clés en InfoSec

```
Risk Assessment
      ↓
Security Planning
      ↓
Implementation of Security Controls
      ↓
Monitoring & Detection
      ↓
Incident Response
      ↓
Disaster Recovery
      ↓
Continuous Improvement ──→ (retour au début)
```

- **SIEM** : collecte et analyse les événements de sécurité
- **Incident Response** : isolation → éradication → recovery
- **Continuous Improvement** : audits réguliers, mise à jour face aux nouvelles threats

---

## Objectifs de l'InfoSec

- Protéger les données sensibles (données personnelles, secrets commerciaux)
- Assurer la **business continuity**
- Maintenir la **regulatory compliance**
- Préserver la réputation de l'organisation
- Protéger la **intellectual property**
- Permettre une transformation numérique sécurisée

## Outils — Vue d'ensemble

| Catégorie | Exemples |
|---|---|
| Firewall | Contrôle du trafic réseau |
| IDS/IPS | Détection/blocage d'activités suspectes |
| SIEM | Collecte et analyse d'événements |
| Vulnerability scanners | Détection de failles |
| Penetration testing tools | Metasploit, Burp Suite |
| Encryption tools | Protection confidentialité/intégrité |

### Outils spécifiques au Penetration Testing

| Outil | Usage |
|---|---|
| **Nmap** | Network scanning & discovery |
| **Wireshark** | Analyse de protocoles réseau |
| **Metasploit** | Exploitation framework |
| **Burp Suite** | Test de sécurité web |
| **John the Ripper** | Password cracking |

> [!warning] Éthique & Légalité
> L'utilisation de ces outils requiert **toujours une autorisation explicite**. Tout test sans autorisation est illégal, quelle que soit l'intention.
