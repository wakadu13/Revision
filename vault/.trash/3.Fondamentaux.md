# Network Security — Fondamentaux

> [!info] Résumé en 2 phrases
> La network security protège les réseaux et les données qui y transitent contre les menaces internes et externes. Elle repose sur plusieurs couches de défense complémentaires, car aucun mécanisme seul ne suffit à garantir une protection totale.

---

## Éléments Clés

| Élément | Rôle |
|---|---|
| **Firewall** | Filtre le trafic entre réseau interne (trusted) et externe (untrusted) |
| **IDS/IPS** | Détecte et/ou bloque automatiquement les activités suspectes |
| **VPN** | Tunnel chiffré sur réseau public (ex: accès distant des employés) |
| **Access Control** | Authentication + Authorization des utilisateurs |
| **Encryption** | Protège les données en transit et au repos |

> [!warning] Limites du Firewall
> Un firewall est une **première ligne de défense**, pas une protection complète. Des techniques avancées permettent de le contourner — d'où la nécessité d'une défense en profondeur (**defense in depth**).

---

## Surface d'Attaque — Facteurs d'Expansion

- Adoption du **cloud computing**
- Prolifération des **IoT** devices
- Généralisation du **remote work**

Ces facteurs augmentent significativement la surface exposée aux threats.

---

## Responsabilités

```
CISO
  └── Network Security Manager
        ├── Network Administrators    → opérations quotidiennes
        ├── Security Analysts         → monitoring
        ├── Penetration Testers       → tests d'intrusion simulés
        └── Compliance Officers       → conformité réglementaire
```

- Le **CISO** définit la stratégie globale
- Le **CIO / IT Director** alloue les ressources
- Les **Penetration Testers** (internes ou externes) simulent des attaques réelles pour identifier les vulnérabilités

---

## Conséquences d'une Brèche Réseau

- Pertes financières
- Dommages réputationnels
- Responsabilités légales
- Interruptions opérationnelles
