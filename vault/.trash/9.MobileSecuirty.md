# Mobile Security

> [!info] Résumé en 2 phrases
> La Mobile Security vise à protéger les appareils mobiles, les données qu'ils contiennent et les réseaux auxquels ils se connectent contre un large spectre de menaces. Elle s'articule en quatre couches complémentaires : sécurité de l'appareil, des données, du réseau et des applications.

---

## 1. Les 4 couches de protection

### 1.1 Device Security
- **Passcodes** : première barrière d'accès à l'appareil.
- **Biometric authentication** : empreinte digitale, reconnaissance faciale — lié à des caractéristiques physiques uniques.
- **Remote wipe** : effacement à distance de toutes les données en cas de perte ou vol.

### 1.2 Data Security
- **Chiffrement** : les données sont rendues illisibles sans la clé de déchiffrement correcte.
- **Secure backups** : copies de sauvegarde stockées en lieu sûr pour prévenir la perte définitive.
- **Data Loss Prevention (DLP)** : stratégies empêchant le partage ou la fuite accidentelle d'informations sensibles.

> [!abstract] Data Loss Prevention (DLP)
> Ensemble de politiques et d'outils techniques visant à détecter et bloquer les transferts non autorisés de données sensibles, qu'ils soient accidentels ou malveillants.

### 1.3 Network Security
- **VPN** (Virtual Private Network) : tunnel chiffré protégeant les données en transit, notamment sur les réseaux Wi-Fi publics.
- **Secure communication protocols** : garantissent la confidentialité et l'intégrité des échanges entre l'appareil et les services distants.

> [!warning] Erreur classique
> Se connecter à un réseau Wi-Fi public sans VPN expose les données en transit à une interception triviale (**Man-in-the-Middle attack**). Les réseaux publics doivent être considérés comme hostiles par défaut.

### 1.4 Application Security
- **App vetting** : sélection rigoureuse des applications avant installation ; privilégier les stores officiels.
- **Permission management** : contrôle granulaire des accès accordés à chaque application (localisation, contacts, caméra, etc.).
- **Secure development practices** : les développeurs doivent intégrer la sécurité dès la conception (**Security by Design**).

> [!warning] Point critique
> Une application demandant des permissions excessives par rapport à sa fonction est un signal d'alerte. Le principe du **moindre privilège** s'applique aussi aux apps mobiles.

---

## 2. Menaces principales

| Menace | Description |
|---|---|
| **Malicious apps** | Applications conçues pour corrompre l'appareil ou exfiltrer des données |
| **Unsecured networks** | Réseaux Wi-Fi publics permettant l'interception des communications |
| **Data theft** | Vol de données personnelles, financières ou professionnelles |
| **Unauthorized access** | Accès physique à un appareil non verrouillé ou mal protégé |

---

## 3. Responsabilités

| Rôle | Responsabilité |
|---|---|
| **IT Department** | Déploiement et gestion des solutions de sécurité (chiffrement, réseaux sécurisés) |
| **CISO** | Stratégie globale, gestion des risques, conformité réglementaire |
| **Security Teams** | Penetration testing, identification et correction des vulnérabilités |
| **IT Security Managers** | Supervision quotidienne, application des politiques, adaptation aux nouvelles menaces |
