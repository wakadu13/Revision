# Les temps du passé
Retour : [[00 - Sommaire TOEIC Grammar]] · Précédent : [[07 - Le présent et l'impératif]] · Suite : [[09 - Les modaux et le futur]]

L'anglais compte trois grandes formes de passé : le ***present perfect***, le **prétérit** et le ***past perfect***. Chacune existe à la forme **simple** et à la forme **en -ING** (progressive), soit six formes au total.

## 1. Le present perfect

### Le present perfect simple

**Construction**

- Affirmative (voix active) : **sujet + have / has (+ not) + participe passé** : *They have worked here for 30 years*, *I have sent the file*.
- Interrogative : **Have / Has (+ not) + sujet + participe passé ?** : *Has she fallen on the floor?*
- Voix passive : **sujet + have / has (+ not) + been + participe passé** : *The roast has been baked*.

Certains auxiliaires et modaux changent de forme au *present perfect* :

| Présent | Present perfect |
|---|---|
| is | has been |
| am / are | have been |
| have | have had |
| do | Ø |
| can | have been able |
| will, shall, may | Ø |
| must | have had to |

**Emplois** : le *present perfect* est un **pont entre le présent et le passé**.

- **Action terminée qui a une incidence sur le présent** (passé récent) : *Erik has failed his exam again*, *They have passed through the customs*.
- **Passé vague, non daté** : ce n'est pas la date qui compte, mais l'action : *The seamstress has finished the gown*.
- **Action qui vient de se terminer**, avec *just* : *They have just finished the rehearsal*.
- **Action qui n'a pas encore eu lieu** (négation, *not… yet*) : *The operator has not called them yet*.

**Durée et date : *for* et *since*** (le *present perfect* a alors une valeur de présent)

| | Sens | Exemples |
|---|---|---|
| **for** | **durée** (« depuis », « cela fait… que ») | *for a minute, for an hour, for a few weeks* : *He has written this book for three years* |
| **since** | **point de départ** (« depuis ») | *since last year, since Monday, since her graduation, since she was born* : *He has written this book since December* |

### Le present perfect en -ING

- Affirmatif : **have / has (+ not) + been + -ING** ; interrogatif : **Have / Has (+ not) + sujet + been + -ING ?**
- **Action en cours** commencée dans le passé (on insiste sur la continuité ou la répétition ; en français, on emploie le présent) : *The accountant has been working on the balance sheet since this morning*.
- **Action passée subjective** ayant une incidence sur le présent, avec une émotion (surprise, irritation, fierté, joie) : *Somebody has been spitting on the table!*, *They have been sleeping for several nights in the mountains*.

## 2. Le prétérit

### Le prétérit simple

**Construction**

- Verbes réguliers, affirmatif : **base verbale + -ed** : *I advised them*, *We skied together*. Redoublement de la consonne pour un verbe à une seule voyelle courte (*span → spanned*, *stun → stunned*).
- Négatif (tous les verbes) : **did not + base verbale** : *They didn't warn us*.
- Interrogatif : **Did + sujet + base verbale ?** : *Did you write this paper?*
- Passif : **was / were (+ not) + participe passé** : *The TV sets were sold out in a few hours* ; interrogatif : **Was / Were (+ not) + being + participe passé** : *The match was being commented by an expert*.

Les auxiliaires et modaux au prétérit :

| Présent | Prétérit |
|---|---|
| am / is | was |
| are | were |
| have | had |
| do | did |
| can | could |
| will | would |
| shall | should |
| may | might |
| must | had to |

**Prétérit modal** : le prétérit introduit par *if* exprime une incertitude, une hypothèse. Avec *be*, on emploie ***were*** à toutes les personnes : *If she were accepted in the team, we would gain time*, *If you stayed longer, you could become fluent*.

**Emploi** : le prétérit s'emploie pour une action **datée et terminée**, située à un moment précis du passé. Contrairement au *present perfect*, il marque une **rupture** entre le passé et le présent. Il s'accompagne d'expressions comme *earlier, before, ago, in* + année.

> [!example] Present perfect ou prétérit ?
> *He **has played** this part for two years* → il joue ce rôle depuis deux ans (et cela continue).
> *He **played** this part for two years* → il a joué ce rôle pendant deux ans (et c'est terminé).

### Le prétérit en -ING

- Déclaratif : **sujet + was / were (not) + base verbale + -ING** ; interrogatif : **was / were (not) + sujet + base verbale + -ING ?** : *They were not sleeping*, *Were they going home?*
- **Durée et progression** : « en train de » ou imparfait français, souvent avec *while* et *when* : *While the CEO was talking, the strikers entered the meeting room*.
- **Anticipation et inachevé** : oppose une action ponctuelle (prétérit simple) à une action inachevée ou à venir : *She replied she was going to deal with it as soon as possible*.

## 3. Le past perfect

### Le past perfect simple

- Déclaratif (à toutes les personnes) : **had (+ not) + participe passé** : *If I had been him, I would not have signed the contract*.
- Passif : **sujet + had (+ not) + been + participe passé** : *The news had been misunderstood*.
- Interrogatif : **Had (+ not) + sujet + participe passé ?** : *Had he really grasped the meaning of all this?*

Le *past perfect* (ou *pluperfect*) est le **plus-que-parfait** : le passé du passé.

- **Concordance des temps** : introduit par un passé, il désigne le passé du passé : *I wondered whether they had been aware of the situation*, *She replied that she had not been informed*.
- **Sens de « trop tard »** : *If you had watched the program, you would have understood…*, *Had you called them earlier, you would have known…*

### Le past perfect en -ING

- Déclaratif : **had (+ not) been + -ING** ; interrogatif : **Had (not) + sujet + been + -ING ?**
- Même sens que le *pluperfect* simple, en insistant sur la **durée** de l'action et sur l'**émotion** : *I didn't know they had been fighting for years on this project*, *I wish I had been working out in that gym!*

## 5. Récapitulatif de la conjugaison anglaise

| Temps | Forme simple | Forme en -ING |
|---|---|---|
| **Present** | *He laughs* (il rit) | *He is laughing* (il est en train de rire) |
| **Present perfect** | *He has laughed* (il rit depuis… / il a ri) | *He has been laughing* (il rit depuis… / il a ri longtemps) |
| **Preterit** | *He laughed* (il a ri / il riait) | *He was laughing* (il riait / il était en train de rire) |
| **Pluperfect** | *He had laughed* (il avait ri) | *He had been laughing* (il avait ri longtemps) |
| **Future** | *He will laugh* (il rira) | *He will be laughing* (il sera en train de rire) |
| **Future perfect** | *He will have laughed* (il aura ri) | *He will have been laughing* (il aura ri longtemps) |
| **Present conditional** | *He would laugh* (il rirait) | *He would be laughing* (il serait en train de rire) |
| **Past conditional** | *He would have laughed* (il aurait ri) | *He would have been laughing* (il aurait ri longtemps) |

> [!warning] Pièges TOEIC
> - **Date passée précise** (*back from 1952*, *in 1978*, *when I worked for…*) → prétérit. **Depuis** (*since 1978*, *for more than 300 years*) → *present perfect*.
> - *Since* + point de départ, *for* + durée : avec l'un des deux, le *present perfect* a une valeur de présent.
> - Conditionnel passé (*would have loved*) dans la principale → *past perfect* (*If … had not been so busy*) dans la subordonnée.

> [!tip] À retenir
> - *Present perfect* : *have / has + participe passé* ; lien avec le présent.
> - Prétérit : action datée et terminée ; *ago, in 1990, last year*.
> - *Past perfect* : *had + participe passé* ; passé du passé, regret (« trop tard »).
> - Les formes en -ING insistent sur la **durée** ou l'**émotion**.
