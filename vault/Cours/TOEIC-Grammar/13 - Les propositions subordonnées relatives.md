# Les propositions subordonnées relatives
Retour : [[00 - Sommaire TOEIC Grammar]] · Précédent : [[12 - Le discours indirect]]

Les pronoms relatifs anglais sont : ***who, whom, whose, which, that, Ø, where, when***. Ils relient un **nom antécédent** à une proposition subordonnée relative qui sert à préciser cet antécédent. Leur choix dépend de leur **fonction grammaticale** dans la relative et de la **nature de l'antécédent** (animé ou non animé). Ils peuvent être accompagnés de prépositions (*for, from, in, with…*).

Les animés sont en général des êtres humains, parfois des animaux. Les non-animés sont les choses, les lieux, les concepts et les situations.

## Tableau récapitulatif

| Fonction | Animé | Non animé |
|---|---|---|
| **Sujet** | *who* / *that* : *The grocer **who / that** sells this produce has just turned 60.* | *which* / *that* : *The menus **which / that** are indicated on the right page…* |
| **COD** | *whom* / *that* / Ø : *The baby-sitter **whom / that / Ø** you hired for your children…* | *which* / *that* / Ø : *The engine **which / that / Ø** the mechanic has been fixing…* |
| **COI** (avec préposition) | *at whom* / *whom … at* : *The child **at whom** you smiled…* | *for which* / *which … for* : *The watch **for which** she's been looking…* |
| **Génitif** (possession) | *whose* : *The engineer **whose** project is so demanding…* | *whose* ou *of which* : *The room **whose** furniture is all white…* / *the furniture **of which*** |
| **Lieu** | | *where* / *in which* : *The café **where** we had breakfast…* |
| **Temps** | | *when* / *in which* / *during which* : *The era **when** dinosaurs lived…* |

> [!warning] Relative descriptive
> Une relative **descriptive** (avec virgule) ne peut être construite ni avec ***that*** ni avec le pronom relatif **zéro** : *My sister Sybil, **who** I feel so close to…* (et non *that*).

## Comment choisir au TOEIC

1. **L'antécédent est-il animé ?** (*who / whom* / *whose*) ou non animé (*which*).
2. **Quelle fonction dans la relative ?** Sujet (*who / which / that*), COD (*whom / which / that / Ø*), possession (*whose*), lieu (*where*), temps (*when*).
3. **Y a-t-il déjà un sujet dans la relative ?** Si oui (*the manor house … has just flown away*), le relatif n'est pas sujet.

> [!example] Exemples
> - *organizations **who** lead the creative economy* : relatif sujet animé → *who lead* (*whose lead* impliquerait une possession, *which lead* ne convient pas à un animé, et un relatif zéro est impossible en sujet).
> - *Melvin Sparks **whose** laboratory is based in Cairns* : relation d'appartenance → *whose*.
> - *The manor house **the roof of which** has just flown away* : génitif d'inanimé.
> - *Anyone **whose** family situation has changed* : génitif d'animé.
> - *… particularly poor in the public and not-for-profit sectors, **where** over two-thirds report…* : pronom relatif de lieu (*where*) ; *which* serait sujet ou objet, *during which* et *when* indiquent un moment.

> [!warning] Pièges TOEIC
> - *Who's* = *who is* (contraction), à ne pas confondre avec *whose*.
> - *Whom* = fonction **objet** pour un animé, *who* = fonction **sujet**.
> - Pour un génitif d'inanimé : *the manor house **the roof of which*** (ou *whose roof*), et non *the manor house which roof* (*which roof* signifierait « quelle toiture »).
> - *That* ne s'emploie ni après une virgule ni après une préposition.

> [!tip] À retenir
> - Animé sujet : *who* ; animé COD : *whom* ; inanimé sujet ou COD : *which / that*.
> - Possession : *whose* (animé et non animé).
> - Lieu : *where* ; temps : *when*.
> - Après une virgule (relative descriptive) : ni *that* ni Ø.
