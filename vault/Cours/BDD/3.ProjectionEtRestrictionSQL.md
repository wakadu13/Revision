# SQL — Projection & Restriction
Retour : [[00 - Sommaire BDD|Sommaire]] · Précédent : [[2.AlgèbreRelationnel]] · Suite : [[4.ComplementSQL]]

> [!info] Résumé en 2 phrases
> La projection (`SELECT`) choisit les **colonnes** à afficher, tandis que la restriction (`WHERE`) filtre les **lignes** selon une condition. Ces deux opérations algébriques sont la base de toute requête SQL.

---

## Structure de base

```sql
SELECT liste_attributs      -- Projection : quelles colonnes ?
FROM nom_table              -- Source
WHERE condition;            -- Restriction : quelles lignes ?
```

---

## Projection — SELECT

> [!abstract] Projection
> Réduit la dimension d'un tuple en ne conservant que certains attributs. Mnémotechnique : *un projecteur éclaire certaines colonnes*.

```sql
-- Toutes les colonnes
SELECT * FROM Personne;

-- Colonnes spécifiques
SELECT nom, age FROM Personne;

-- Sans doublons
SELECT DISTINCT ville FROM Personne;
```

---

## Restriction — WHERE

> [!abstract] Restriction
> Agit sur le nombre d'occurrences (lignes) en filtrant selon un ou plusieurs critères.

### Tableau des opérateurs

| Type | Opérateur | Exemple | Signification |
|---|---|---|---|
| **Comparaison** | `=` | `age = 18` | égal |
| | `!=` ou `<>` | `age != 18` | différent |
| | `>` `<` `>=` `<=` | `age > 18` | comparaison classique |
| **Intervalle** | `BETWEEN` | `age BETWEEN 18 AND 20` | bornes incluses |
| **Liste** | `IN` | `ville IN ('Paris','Lyon')` | appartient à la liste |
| | `NOT IN` | `ville NOT IN ('Paris')` | n'appartient pas |
| **Texte** | `LIKE 'A%'` | `nom LIKE 'A%'` | commence par A |
| | `LIKE '%a'` | `nom LIKE '%a'` | finit par a |
| | `LIKE '%an%'` | `nom LIKE '%an%'` | contient "an" |
| **NULL** | `IS NULL` | `email IS NULL` | valeur absente |
| | `IS NOT NULL` | `email IS NOT NULL` | valeur présente |
| **Logique** | `AND` | `age > 18 AND ville='Toulon'` | ET |
| | `OR` | `ville='Paris' OR ville='Lyon'` | OU |
| | `NOT` | `NOT ville='Paris'` | négation |

> [!warning] NULL — piège classique
> `NULL` ne se compare **jamais** avec `=` ou `!=`.
> ```sql
> -- ❌ Ne fonctionne PAS
> WHERE email = NULL
> -- ✅ Correct
> WHERE email IS NULL
> ```

## Corrigés — BDD Pokémon

```sql
-- 1. Tous les Pokémon
SELECT * FROM pokemon;

-- 2. Nom des Pokémon
SELECT nom FROM pokemon;

-- 3. Tous les dresseurs
SELECT * FROM dresseur;

-- 4. Nom et âge des dresseurs
SELECT nom, age FROM dresseur;

-- 5. Nom des types
SELECT nom FROM type;

-- 6. Dresseurs de plus de 18 ans
SELECT nom FROM dresseur WHERE age > 18;

-- 7. Pokémon avec un type secondaire
SELECT * FROM pokemon WHERE type_secondaire IS NOT NULL;

-- 8. Dresseurs > 30 ans ET nom commence par N
SELECT * FROM dresseur WHERE age > 30 AND nom LIKE 'N%';

-- 9. Dresseurs > 15 ans ET sexe féminin
SELECT * FROM dresseur WHERE age > 15 AND sexe = 'F';

-- 10. Dresseurs dont l'âge est 18 ou 25
SELECT nom, age FROM dresseur WHERE age IN (18, 25);

-- 11. Pokémon dont le type principal est 4 ou 10
SELECT * FROM pokemon WHERE type_principal IN (4, 10);

-- 12. Dresseurs entre 10 et 20 ans
SELECT * FROM dresseur WHERE age BETWEEN 10 AND 20;

-- 13. Arènes dont le type favori est 9
SELECT * FROM arene WHERE type_favori = 9;

-- 14. Dresseurs dont l'âge n'est PAS entre 10 et 15
SELECT * FROM dresseur WHERE age NOT BETWEEN 10 AND 15;

-- 15. Pokémon dont le nom commence par P
SELECT * FROM pokemon WHERE nom LIKE 'P%';

-- 16. Dresseurs dont le nom contient "a"
SELECT * FROM dresseur WHERE nom LIKE '%a%';

-- 17. Dresseurs dont le nom finit par "e"
SELECT * FROM dresseur WHERE nom LIKE '%e';

-- 18. Pokémon sans type secondaire
SELECT * FROM pokemon WHERE type_secondaire IS NULL;

-- 19. Dresseurs dont l'id région est 3
SELECT * FROM dresseur WHERE id_region = 3;

-- 20. Noms des dresseurs sans doublons
SELECT DISTINCT nom FROM dresseur;
```
