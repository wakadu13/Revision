# Terminologie Clé des Réseaux

---

Il existe de nombreux termes différents dans le domaine des technologies de l'information. Cependant, nous n'avons besoin d'en connaître que quelques-uns, seulement les plus essentiels. Les technologies de l'information ont pris une telle ampleur qu'elles égalent le secteur médical, si elles ne le dépassent pas déjà. Le nombre de langages de programmation, de fonctions, de protocoles, de procédures différentes, de domaines d'application, de détails, et en même temps, le nombre d'erreurs qui peuvent survenir. Tous ces domaines sont si vastes que vous pouvez spécialiser toute votre carrière dans 1 ou 2 domaines.

La terminologie clé est l'alphabet de base que nous devons connaître pour comprendre ce dont nous parlerons dans les autres modules. Nous avons créé une liste contenant de nombreux protocoles différents, mais qui restent les plus courants, avec leurs descriptions, afin de créer cette base. Il est important de noter que cette liste est incomplète, et que nous aborderons un ou deux autres protocoles dans d'autres modules. Cependant, nous vous recommandons de consulter cette liste de temps en temps et de l'étoffer au fur et à mesure que vous apprenez de nouveaux protocoles.

|**Protocole**|**Acronyme**|**Description**|
|---|---|---|
|Confidentialité Équivalente au Filaire (Wired Equivalent Privacy)|`WEP`|WEP est un type de protocole de sécurité qui était couramment utilisé pour sécuriser les réseaux sans fil.|
|Secure Shell|`SSH`|Un protocole réseau sécurisé utilisé pour se connecter à un système distant et y exécuter des commandes.|
|Protocole de Transfert de Fichiers (File Transfer Protocol)|`FTP`|Un protocole réseau utilisé pour transférer des fichiers d'un système à un autre.|
|Protocole Simple de Transfert de Courrier (Simple Mail Transfer Protocol)|`SMTP`|Un protocole utilisé pour envoyer et recevoir des e-mails.|
|Protocole de Transfert Hypertexte (Hypertext Transfer Protocol)|`HTTP`|Un protocole client-serveur utilisé pour envoyer et recevoir des données sur Internet.|
|Server Message Block|`SMB`|Un protocole utilisé pour partager des fichiers, des imprimantes et d'autres ressources sur un réseau.|
|Système de Fichiers en Réseau (Network File System)|`NFS`|Un protocole utilisé pour accéder à des fichiers sur un réseau.|
|Protocole Simple de Gestion de Réseau (Simple Network Management Protocol)|`SNMP`|Un protocole utilisé pour gérer les périphériques réseau.|
|Accès Protégé Wi-Fi (Wi-Fi Protected Access)|`WPA`|WPA est un protocole de sécurité sans fil qui utilise un mot de passe pour protéger les réseaux sans fil contre les accès non autorisés.|
|Protocole d'Intégrité de Clé Temporaire (Temporal Key Integrity Protocol)|`TKIP`|TKIP est également un protocole de sécurité utilisé dans les réseaux sans fil, mais il est moins sécurisé.|
|Protocole d'Heure Réseau (Network Time Protocol)|`NTP`|Il est utilisé pour synchroniser l'heure des ordinateurs sur un réseau.|
|Réseau Local Virtuel (Virtual Local Area Network)|`VLAN`|C'est un moyen de segmenter un réseau en plusieurs réseaux logiques.|
|Protocole de Trunking VLAN (VLAN Trunking Protocol)|`VTP`|VTP est un protocole de couche 2 utilisé pour établir et maintenir un réseau local virtuel (VLAN) s'étendant sur plusieurs commutateurs.|
|Protocole d'Information de Routage (Routing Information Protocol)|`RIP`|RIP est un protocole de routage à vecteur de distance utilisé dans les réseaux locaux (LAN) et les réseaux étendus (WAN).|
|Open Shortest Path First|`OSPF`|Il s'agit d'un protocole de passerelle intérieure (IGP) pour le routage du trafic au sein d'un seul Système Autonome (AS) dans un réseau de Protocole Internet (IP).|
|Protocole de Routage de Passerelle Intérieure (Interior Gateway Routing Protocol)|`IGRP`|IGRP est un protocole de passerelle intérieure propriétaire de Cisco, conçu pour le routage au sein de systèmes autonomes.|
|Protocole de Routage de Passerelle Intérieure Amélioré (Enhanced Interior Gateway Routing Protocol)|`EIGRP`|C'est un protocole de routage à vecteur de distance avancé qui est utilisé pour router le trafic IP au sein d'un réseau.|
|Pretty Good Privacy|`PGP`|PGP est un programme de chiffrement utilisé pour sécuriser les e-mails, les fichiers et d'autres types de données.|
|Protocole de Transfert de Nouvelles sur le Réseau (Network News Transfer Protocol)|`NNTP`|NNTP est un protocole utilisé pour distribuer et récupérer des messages dans des groupes de discussion sur Internet.|
|Cisco Discovery Protocol|`CDP`|C'est un protocole propriétaire développé par Cisco Systems qui permet aux administrateurs réseau de découvrir et de gérer les périphériques Cisco connectés au réseau.|
|Hot Standby Router Protocol|`HSRP`|HSRP est un protocole utilisé dans les routeurs Cisco pour assurer la redondance en cas de défaillance d'un routeur ou d'un autre périphérique réseau.|
|Protocole de Redondance de Routeur Virtuel (Virtual Router Redundancy Protocol)|`VRRP`|C'est un protocole utilisé pour fournir une affectation automatique des routeurs de Protocole Internet (IP) disponibles aux hôtes participants.|
|Protocole Spanning Tree (Spanning Tree Protocol)|`STP`|STP est un protocole réseau utilisé pour garantir une topologie sans boucle dans les réseaux Ethernet de couche 2.|
|Terminal Access Controller Access-Control System|`TACACS`|TACACS est un protocole qui fournit une authentification, une autorisation et une comptabilisation centralisées pour l'accès au réseau.|
|Protocole d'Initiation de Session (Session Initiation Protocol)|`SIP`|C'est un protocole de signalisation utilisé pour établir et terminer des sessions de voix, de vidéo et de multimédia en temps réel sur un réseau IP.|
|Voix sur IP (Voice Over IP)|`VOIP`|La VoIP est une technologie qui permet de passer des appels téléphoniques via Internet.|
|Protocole d'Authentification Extensible (Extensible Authentication Protocol)|`EAP`|EAP est un framework d'authentification qui prend en charge plusieurs méthodes d'authentification, telles que les mots de passe, les certificats numériques, les mots de passe à usage unique et l'authentification par clé publique.|
|Lightweight Extensible Authentication Protocol|`LEAP`|LEAP est un protocole d'authentification sans fil propriétaire développé par Cisco Systems. Il est basé sur le Protocole d'Authentification Extensible (EAP) utilisé dans le Protocole Point à Point (PPP).|
|Protected Extensible Authentication Protocol|`PEAP`|PEAP est un protocole de sécurité qui fournit un tunnel chiffré pour les réseaux sans fil et d'autres types de réseaux.|
|Systems Management Server|`SMS`|SMS est une solution de gestion de systèmes qui aide les organisations à gérer leurs réseaux, systèmes et appareils mobiles.|
|Microsoft Baseline Security Analyzer|`MBSA`|C'est un outil de sécurité gratuit de Microsoft qui est utilisé pour détecter les vulnérabilités de sécurité potentielles dans les ordinateurs, réseaux et systèmes Windows.|
|Système de Contrôle et d'Acquisition de Données (Supervisory Control and Data Acquisition)|`SCADA`|C'est un type de système de contrôle industriel utilisé pour surveiller et contrôler des processus industriels, tels que ceux de la fabrication, de la production d'énergie, et du traitement de l'eau et des déchets.|
|Réseau Privé Virtuel (Virtual Private Network)|`VPN`|Le VPN est une technologie qui permet aux utilisateurs de créer une connexion sécurisée et chiffrée à un autre réseau via Internet.|
|Internet Protocol Security|`IPsec`|IPsec est un protocole utilisé pour fournir une communication sécurisée et chiffrée sur un réseau. Il est couramment utilisé dans les VPN, ou Réseaux Privés Virtuels, pour créer un tunnel sécurisé entre deux appareils.|
|Protocole de Tunnelisation Point à Point (Point-to-Point Tunneling Protocol)|`PPTP`|C'est un protocole utilisé pour créer un tunnel sécurisé et chiffré pour l'accès à distance.|
|Traduction d'Adresse Réseau (Network Address Translation)|`NAT`|La NAT est une technologie qui permet à plusieurs appareils sur un réseau privé de se connecter à Internet en utilisant une seule adresse IP publique. La NAT fonctionne en traduisant les adresses IP privées des appareils du réseau en une seule adresse IP publique, qui est ensuite utilisée pour se connecter à Internet.|
|Retour Chariot et Saut de Ligne (Carriage Return Line Feed)|`CRLF`|Combine deux caractères de contrôle pour indiquer la fin d'une ligne et le début d'une nouvelle pour certains formats de fichiers texte.|
|JavaScript et XML Asynchrones (Asynchronous JavaScript and XML)|`AJAX`|Technique de développement web qui permet de créer des pages web dynamiques en utilisant JavaScript et XML/JSON.|
|Internet Server Application Programming Interface|`ISAPI`|Permet de créer des extensions web axées sur la performance pour les serveurs web en utilisant un ensemble d'API.|
|Identifiant Uniforme de Ressource (Uniform Resource Identifier)|`URI`|C'est une syntaxe utilisée pour identifier une ressource sur Internet.|
|Localisateur Uniforme de Ressource (Uniform Resource Locator)|`URL`|Sous-ensemble d'URI qui identifie une page web ou une autre ressource sur Internet, incluant le protocole et le nom de domaine.|
|Échange de Clés Internet (Internet Key Exchange)|`IKE`|IKE est un protocole utilisé pour établir une connexion sécurisée entre deux ordinateurs. Il est utilisé dans les réseaux privés virtuels (VPN) pour fournir l'authentification et le chiffrement pour la transmission de données, protégeant les données de l'écoute et de la falsification externes.|
|Encapsulation Générique de Routage (Generic Routing Encapsulation)|`GRE`|Ce protocole est utilisé pour encapsuler les données transmises à l'intérieur du tunnel VPN.|
|Remote Shell|`RSH`|C'est un programme sous Unix qui permet d'exécuter des commandes et des programmes sur un ordinateur distant.|
