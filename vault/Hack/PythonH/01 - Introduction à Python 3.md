# Introduction à Python 3

---

Bienvenue dans `Introduction à Python 3`. Ce module couvrira la plupart des éléments essentiels que vous devez connaître pour démarrer avec l'écriture de scripts en Python. Que vous ayez une expérience en informatique ou que vous débutiez, ce module tentera de vous `guider` dans le processus de création de scripts petits mais utiles. Ce module vous présentera une quantité de code qui, selon votre expérience, vous semblera juste suffisante ou assez importante. Mais ne craignez rien, nous allons surmonter cela ensemble.

Alors, pourquoi apprendre Python, pourrait-on se demander ? Python est actuellement l'un des langages de script les `plus populaires`. Cela en fait un choix populaire pour l'`automatisation` des tâches quotidiennes ou le développement d'`outils`. Dans le monde de la sécurité de l'information (InfoSec), de nombreuses preuves de concept (PoC, Proof of Concepts) sont écrites en Python, tout comme de nombreux outils populaires pour les tests d'intrusion (penetration testing). La simplicité du langage le rend attrayant lorsqu'un besoin d'« écrire quelque chose rapidement » se fait sentir. Pourtant, la flexibilité du langage et le soutien de sa communauté en font également un candidat idéal pour des projets de plus grande envergure. Que vous ayez besoin d'écrire un simple script pour automatiser une tâche répétitive sur un site web, de collecter ou d'analyser de grandes quantités de données, de réaliser des attaques par débordement de tampon (buffer overflow), de créer un service interactif ou quelque chose de complètement différent, Python facilite le développement.

Python est un `langage interprété`, ce qui signifie que le code lui-même n'est pas compilé en code machine comme le code C. Au lieu de cela, il est interprété par le programme Python, et les instructions contenues dans le ou les scripts sont exécutées. Python est un langage de haut niveau, ce qui signifie que les scripts que nous produisons sont simplifiés pour notre convenance, de sorte que nous n'avons pas à nous soucier de la gestion de la mémoire, des appels système, etc. De plus, Python est un langage `à usage général` et `multi-paradigme`, ce qui est une façon élégante de dire « vous pouvez l'utiliser pour la plupart des choses avec facilité » et « peu importe que vous préfériez un style ou un autre ».

Quant au style de codage, nous aborderons en douceur le style orienté objet, car cela simplifie grandement le raisonnement sur le code. Essentiellement, la programmation orientée objet vous semblera probablement moins intimidante si vous avez déjà joué avec des blocs ou des briques, que ce soit sous forme numérique ou physique. Enfin, la rumeur veut que Python soit facile à lire, surtout au début. Cela est peut-être dû à sa grande ressemblance avec la langue anglaise et à ses exigences strictes en matière d'indentation correcte du code.

Dans ce module, il y aura des exemples de code, et en grand nombre. Il est fortement recommandé de taper tout le code à la main au fur et à mesure de votre lecture et de vous abstenir de copier-coller. Cela vous aidera à vous mettre dans le bain et à mémoriser ce que vous avez appris. Il est également fortement recommandé d'explorer et de vous amuser avec les outils et les techniques enseignés dans ce module. Nous partons du principe que Python 3 est déjà installé sur votre système et que l'exécutable Python 3 se trouve dans le PATH. Une machine virtuelle web avec Python 3 déjà installé et correctement configuré sera fournie pour toutes les sections pertinentes.

Encore une fois, bienvenue dans ce module.
