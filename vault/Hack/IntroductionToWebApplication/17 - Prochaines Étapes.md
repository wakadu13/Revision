# Prochaines Étapes

---

Dans ce module, nous avons appris quelques-unes, mais certainement pas toutes, les bases des applications web. Nous devrions maintenant avoir une compréhension fondamentale de la manière dont une application web est construite, de son fonctionnement et des dangers qu'elle peut introduire dans un environnement d'entreprise.

Il est important d'adopter une approche pratique pour approfondir notre compréhension et appliquer les sujets enseignés dans ce module. Nous recommandons de réviser le contenu en parallèle du développement d'une petite application web. Voici quelques-unes des prochaines étapes qui peuvent être suivies :

|**Étape**|**À faire**|
|---|---|
|`1.`|Configurer une VM avec un serveur web|
|`2.`|Créer une page `HTML`|
|`3.`|La concevoir avec `CSS`|
|`4.`|Ajouter quelques fonctions simples avec `JavaScript`|
|`5.`|Programmer une application web simple|
|`6.`|Connecter votre application web à la base de données|
|`7.`|Expérimenter avec des API|
|`8.`|Tester votre application pour diverses vulnérabilités (vulnerabilities) et failles de sécurité|
|`9.`|Essayer d'ajuster votre code et vos configurations pour corriger les vulnérabilités|

Développer une petite application web vous apportera une compréhension beaucoup plus approfondie de la structure et des fonctionnalités. Apprendre à configurer et à gérer un tel serveur web, le rôle de la base de données et la manière dont les différents morceaux de code sont liés entre eux est une expérience inestimable.

Les modules de l'Academy `Web Requests` et `JavaScript Deobfuscation` vous aideront à approfondir les connaissances présentées dans ce module.

Le module `Hacking WordPress` et d'autres modules similaires liés à l'`OWASP Top 10` (comme `SQL Injection Fundamentals`) sont d'excellentes prochaines étapes pour se lancer dans les tests d'intrusion (penetration testing) d'applications web et en apprendre davantage sur les vulnérabilités des applications web et leur exploitation. Enfin, pour appliquer ce que nous avons appris dans ces modules, nous pouvons nous lancer dans l'attaque de quelques machines `Easy` sur [HackTheBox](https://www.hackthebox.eu/).
