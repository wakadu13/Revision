# Algèbre Relationnelle
Retour : [[00 - Sommaire BDD|Sommaire]] · Précédent : [[1.ConceptFondamentaux]] · Suite : [[3.ProjectionEtRestrictionSQL]]

> [!info] Résumé en 2 phrases
> Définie par Codd en 1970, l'algèbre relationnelle est un ensemble d'opérations sur des relations produisant de nouvelles relations — elle est le fondement théorique de SQL. Elle se compose de 4 opérateurs ensemblistes classiques et de 4 opérateurs spécifiques aux tables.

---

| Catégorie | Opérateur | Commutatif |

## Opérateurs Ensemblistes

> [!warning] Prérequis Union, Intersection, Différence
> Les trois premiers opérateurs exigent que R1 et R2 aient **le même schéma** (mêmes attributs, mêmes domaines).

### Union
```
R = UNION(R1, R2)
```
- Tous les tuples de R1 **et** R2
- Doublons **éliminés**

### Intersection
```
R = INTERSECTION(R1, R2)
```
- Uniquement les tuples présents dans R1 **ET** R2

### Différence
```
R = DIFFERENCE(R1, R2)
```
- Uniquement les tuples de R1 **absents** de R2
- ❌ Non commutative : `DIFFERENCE(R1,R2) ≠ DIFFERENCE(R2,R1)`

### Produit Cartésien
```
R = PRODUIT(R1, R2)
```
- Toutes les combinaisons possibles de tuples de R1 × R2
- Degré(R) = Degré(R1) + Degré(R2)
- Card(R) = Card(R1) × Card(R2)

## Opérateurs Spécifiques

### Restriction (Sélection)
```
R = RESTRICTION(R1, condition)
```
- Filtre les **lignes** selon une condition
- Tous les attributs sont conservés
- Opérateurs disponibles : `=  >  <  >=  <=  <>  ET  OU  NON`

```
R = RESTRICTION(R1, Numéro >= 5)
→ conserve uniquement les tuples où Numéro ≥ 5
```

### Projection
```
R = PROJECTION(R1, Liste des attributs)
```
- Filtre les **colonnes** selon une liste d'attributs
- Doublons **éliminés** sur le résultat

```
R = PROJECTION(Personne, Nom)
→ ne retourne que la colonne Nom, sans doublons
```

## La Jointure

> [!abstract] Jointure
> Rapproche les tuples de R1 et R2 selon une condition de comparaison portant sur des attributs définis dans le **même domaine**. Équivalente à un `PRODUIT` suivi d'une `RESTRICTION`. Les attributs de jointure ne sont **pas dupliqués** dans le résultat.

```
R = JOINTURE(R1, R2, Expression de comparaison)
```

### Les trois variantes

| Type | Condition | Fusion des colonnes |
|---|---|---|
| **Thêta-jointure** | Comparaison quelconque (`<`, `>`, `<=`…) | Non |
| **Équijointure** | Égalité stricte (`A1 = A2`) | Non |
| **Jointure naturelle** | Égalité sur attributs **de même nom** | ✅ Oui — fusionnés |

```
# Thêta-jointure + Restriction combinées
Rx1 = JOINTURE(R1, R2, (Age <= AgeC))
Rx  = RESTRICTION(Rx1, (Prix < 50))

# Jointure naturelle sur attribut "Age"
R = JOINTURE(R1, R2, Age)
→ la colonne Age n'apparaît qu'une fois dans R
```

## La Division

> [!abstract] Division
> R1 est divisée par R2, dont le schéma est **strictement inclus** dans celui de R1. Le résultat contient tous les tuples de R1 associés à **toutes** les occurrences de R2.

```
R = DIVISION(R1, R2)
```

> [!warning] Cas d'usage typique
> La division répond aux questions de type **"pour tous"** : *"Quels clients ont commandé TOUS les produits du catalogue ?"*. Si la réponse implique une universalité, penser à la division.
