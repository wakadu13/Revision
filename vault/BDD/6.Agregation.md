# SQL — Fonctions d'Agrégation
Retour : [[00 - Sommaire BDD|Sommaire]] · Précédent : [[5.Jointure]]

> [!info] Résumé en 2 phrases
> Les fonctions d'agrégation transforment un ensemble de lignes en **une seule valeur calculée** (compte, somme, moyenne, min, max). Elles s'appliquent après le filtrage `WHERE` et ignorent les valeurs `NULL` (sauf `COUNT(*)`).

---

## Tableau de synthèse

| Fonction | Rôle | Syntaxe |
|---|---|---|
| `COUNT(*)` | Compte toutes les lignes | `SELECT COUNT(*) FROM Table` |
| `COUNT(col)` | Compte les valeurs non-NULL | `SELECT COUNT(col) FROM Table` |
| `SUM(col)` | Additionne | `SELECT SUM(col) FROM Table` |
| `AVG(col)` | Moyenne | `SELECT AVG(col) FROM Table` |
| `MAX(col)` | Valeur maximale | `SELECT MAX(col) FROM Table` |
| `MIN(col)` | Valeur minimale | `SELECT MIN(col) FROM Table` |

---

## Points importants

> [!warning] Règles à retenir
> - `COUNT(*)` → compte **tout**, y compris les NULL
> - `COUNT(colonne)` → **ignore les NULL**
> - `WHERE` filtre les lignes **avant** le calcul
> - Les valeurs `NULL` sont ignorées par `SUM`, `AVG`, `MAX`, `MIN`
> - Plusieurs fonctions d'agrégation peuvent coexister dans une même requête

```sql
-- Exemple combiné
SELECT COUNT(*), AVG(pv), MAX(pv), MIN(pv)
FROM pokemon;
```

## Corrigés — BDD Pokémon

```sql
-- 1. Nombre total de Pokémons
SELECT COUNT(*) FROM pokemon;

-- 2. Moyenne des PV des Pokémons
SELECT AVG(pv) FROM pokemon;

-- 3. PV maximum d'un Pokémon
SELECT MAX(pv) FROM pokemon;

-- 4. Somme des PV de tous les Pokémons
SELECT SUM(pv) FROM pokemon;

-- 5. Nombre de Pokémons ayant plus de 100 PV
SELECT COUNT(*) FROM pokemon
WHERE pv > 100;

-- 6. Nombre de Pokémons dont le type secondaire est NULL
SELECT COUNT(*) FROM pokemon
WHERE type_secondaire IS NULL;

-- 7. Nombre de Pokémons de type principal Dragon
SELECT COUNT(*) FROM pokemon
JOIN type ON pokemon.type_principal = type.id
WHERE type.nom = 'Dragon';

-- 8. Moyenne des PV des Pokémons de type principal Fée
SELECT AVG(pokemon.pv) FROM pokemon
JOIN type ON pokemon.type_principal = type.id
WHERE type.nom = 'Fée';

-- 9. Nombre de Pokémons possédés par des dresseurs de moins de 18 ans
SELECT COUNT(*) FROM posseder
JOIN dresseur ON posseder.id_dresseur = dresseur.id
WHERE dresseur.age < 18;

-- 10. Moyenne des PV des Pokémons capturés après 2024 de type "Insecte"
SELECT AVG(pokemon.pv) FROM pokemon
JOIN posseder ON pokemon.id = posseder.id_pokemon
JOIN type ON pokemon.type_principal = type.id
WHERE type.nom = 'Insecte'
AND YEAR(posseder.date_capture) > 2024;

-- 11. Moyenne des PV des Pokémons capturés avant 2015 par des dresseurs majeurs
SELECT AVG(pokemon.pv) FROM pokemon
JOIN posseder ON pokemon.id = posseder.id_pokemon
JOIN dresseur ON posseder.id_dresseur = dresseur.id
WHERE YEAR(posseder.date_capture) < 2015
AND dresseur.age >= 18;

-- 12. Nombre de Pokémons de type "Feu" capturés après 2018
SELECT COUNT(*) FROM pokemon
JOIN posseder ON pokemon.id = posseder.id_pokemon
JOIN type ON pokemon.type_principal = type.id
WHERE type.nom = 'Feu'
AND YEAR(posseder.date_capture) > 2018;

-- 13. Nombre de Pokémons de type "Eau" possédés par des dresseurs dont le nom commence par "O"
SELECT COUNT(*) FROM pokemon
JOIN posseder ON pokemon.id = posseder.id_pokemon
JOIN dresseur ON posseder.id_dresseur = dresseur.id
JOIN type ON pokemon.type_principal = type.id
WHERE type.nom = 'Eau'
AND dresseur.nom LIKE 'O%';
```
