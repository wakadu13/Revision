# SQL — Tri, Limite, Alias, Union & Concaténation
Retour : [[00 - Sommaire BDD|Sommaire]] · Précédent : [[3.ProjectionEtRestrictionSQL]] · Suite : [[5.Jointure]]

> [!info] Résumé en 2 phrases
> Cette séance complète les opérations de base en ajoutant le tri (`ORDER BY`), la limitation (`LIMIT`), le renommage (`AS`), la fusion (`UNION`) et la concaténation (`||`). Ces opérations agissent uniquement sur l'**affichage**, jamais sur la structure de la base.

---

## Tableau de synthèse

| Mot-clé | Question | Effet |
|---|---|---|
| `ORDER BY` | Dans quel ordre ? | Trie les lignes |
| `LIMIT` | Combien ? | Limite le nombre de résultats |
| `AS` | Comment renommer ? | Renomme une colonne à l'affichage |
| `UNION` | Comment fusionner ? | Combine deux résultats |
| `\|\|` | Comment coller ? | Concatène des valeurs |

---

## ORDER BY — Tri

> [!abstract] ORDER BY
> Définit l'ordre d'affichage des résultats. Par défaut : **croissant**.

```sql
-- Croissant (défaut)
SELECT nom, age FROM Eleve ORDER BY age;
SELECT nom, age FROM Eleve ORDER BY age ASC;

-- Décroissant
SELECT nom, age FROM Eleve ORDER BY age DESC;

-- Tri sur plusieurs colonnes
SELECT nom, age FROM Eleve ORDER BY age DESC, nom ASC;
```

---

## LIMIT — Limitation

> [!abstract] LIMIT
> Restreint le nombre de lignes retournées. Se place **en dernier** dans la requête.

```sql
-- Les 5 premiers résultats
SELECT titre FROM Livre LIMIT 5;

-- Les 5 plus vieux dresseurs
SELECT nom, age FROM dresseur ORDER BY age DESC LIMIT 5;
```

---

## AS — Alias

> [!abstract] AS
> Renomme une colonne **uniquement à l'affichage**. La base de données n'est pas modifiée.

```sql
SELECT titre AS titre_livre FROM Livre;

SELECT nom AS nom_dresseur, age AS age_dresseur FROM dresseur;
```

---

## UNION — Fusion

> [!abstract] UNION
> Combine les résultats de deux requêtes en une seule liste. Les **doublons sont éliminés** automatiquement.

```sql
SELECT titre FROM Livre
UNION
SELECT nom FROM Auteur;
```

> [!warning] Contraintes UNION
> Les deux requêtes doivent avoir :
> - Le **même nombre** de colonnes
> - Des colonnes de **types compatibles**

---

## Concaténation

> [!abstract] Concaténation
> Colle plusieurs valeurs (colonnes ou texte libre) en une seule chaîne avec l'opérateur `||`.

```sql
-- Sans alias
SELECT titre || ' - ' || prix FROM Livre;
-- Résultat : La femme de ménage - 15

-- Avec alias
SELECT titre || ' (' || prix || ')' AS description FROM Livre;
-- Résultat : La femme de ménage (15)
```

## Corrigés — BDD Pokémon

```sql
-- 1. Nom et âge des dresseurs triés par âge croissant
SELECT nom, age FROM dresseur ORDER BY age ASC;

-- 2. Nom des 6 premiers Pokémon
SELECT nom FROM pokemon LIMIT 6;

-- 3. Nom des 5 dresseurs les plus vieux
SELECT nom FROM dresseur ORDER BY age DESC LIMIT 5;

-- 4. Nom et âge des dresseurs avec colonnes renommées
SELECT nom AS nom_dresseur, age AS age_dresseur FROM dresseur;

-- 5. Nom des 3 arènes triées par nom
SELECT nom FROM arene ORDER BY nom ASC LIMIT 3;

-- 6. Dresseurs de plus de 30 ans triés par âge décroissant
SELECT * FROM dresseur WHERE age > 30 ORDER BY age DESC;

-- 7. Ville des arènes avec leur nom sous forme de texte
SELECT nom || ' - ' || ville AS description FROM arene;

-- 8. Description des dresseurs (nom et âge)
SELECT nom || ' (' || age || ' ans)' AS description FROM dresseur;

-- 9. Fusion des noms de Pokémon et de dresseurs
SELECT nom FROM pokemon
UNION
SELECT nom FROM dresseur;

-- 10. Fusion des noms commençant par F
SELECT nom FROM pokemon WHERE nom LIKE 'F%'
UNION
SELECT nom FROM dresseur WHERE nom LIKE 'F%';

-- 11. Pokémon sans type secondaire triés par nom
SELECT nom FROM pokemon 
WHERE type_secondaire IS NULL 
ORDER BY nom ASC;

-- 12. Nom et âge des 3 dresseurs les plus jeunes
SELECT nom, age FROM dresseur ORDER BY age ASC LIMIT 3;

-- 13. Pokémon avec PV entre 50 et 100 triés par PV
SELECT nom FROM pokemon 
WHERE pv BETWEEN 50 AND 100 
ORDER BY pv ASC;
```
